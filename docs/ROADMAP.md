# 自研应用路线图

基于现有 6 款应用（首页/收音机/随身语音/小智/秒表/番茄钟）做增量，应用分区余量约 1MB。

## 候选（按优先级）

1. **晨报宠物** — 晨间摘要 + 健康红绿灯（联动电脑端 cron 数据）
2. **身体线打卡伙伴** — 运动/饮食 streak 追踪，连续 7 天满血动画，断签变蔫
3. **番茄钟 × ActivityWatch 联动** — 电脑端专注数据同步
4. **健康牌** — BLE 广播设备状态

## 原则

- 单玩法约束：设备屏幕一次一个应用，由启动器管理
- 新应用从 `main/apps/app_base.h` 的 APP_ID 枚举 + `app_registry.cc` 注册表接入
- 每新增一个应用同步更新 README 应用表
- 删除类变更须同步清理：注册表/图标绘制/内存预算/串口命令/配网页/CMakeLists（参考 Muse 移除的 7 处深挖清单）
